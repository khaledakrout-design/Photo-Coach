# Guide de Téléchargement — PHOTO COACH APK

Le fichier d'installation Android **PhotoCoach.apk** (21 Mo) a été généré et placé à la racine de votre projet.

---

### Emplacements du fichier APK :
- **`/PhotoCoach.apk`** (à la racine du projet)
- **`/app/PhotoCoach.apk`** (dans le dossier app)
- **`/app/build/outputs/apk/debug/app-debug.apk`** (dossier de compilation)

---

### Comment télécharger le fichier depuis l'explorateur :
1. Dans le panneau de gauche, localisez le fichier **`PhotoCoach.apk`**.
2. **Faites un clic droit** dessus et choisissez **Télécharger** (*Download*).
3. Si votre navigateur affiche un message indiquant que c'est un fichier binaire, validez le téléchargement.
4. Installez le fichier `.apk` sur votre smartphone Android.

---

### Option Alternative (Téléchargement via Exportation ZIP) :
Si votre navigateur bloque le clic direct sur les fichiers `.apk` dans l'explorateur de code :
1. En haut à droite de l'écran AI Studio, cliquez sur le bouton d'exportation (**Download ZIP** / **Export**).
2. Dézippez l'archive sur votre ordinateur : le fichier APK se trouve dans `app/build/outputs/apk/debug/app-debug.apk`.
