# Guide d'installation de PHOTO COACH (APK)

Le fichier d'installation Android **`PhotoCoach.apk`** est maintenant disponible **directement à la racine du projet**.

---

### Comment télécharger l'APK sur votre ordinateur / mobile

1. **Depuis l'explorateur de fichiers de l'éditeur (à gauche)** :
   * Faites un clic droit sur le fichier **`PhotoCoach.apk`** situé tout en haut à la racine du projet.
   * Sélectionnez **Télécharger** (*Download*).
2. **Transfert sur votre mobile** :
   * Envoyez le fichier sur votre smartphone (via câble USB, Google Drive, WhatsApp ou messagerie).
   * Sur votre mobile Android, ouvrez le fichier `PhotoCoach.apk`.
   * Si demandé, autorisez l'installation d'applications de sources inconnues pour votre gestionnaire de fichiers ou navigateur.
   * Cliquez sur **Installer**.

---

### Détails techniques de la version embarquée

* **Nom de l'application** : PHOTO COACH
* **Fichier** : `PhotoCoach.apk` (69 Mo)
* **Moteur d'inférence** : MediaPipe Tasks Vision (EfficientDet-Lite0 quantifié int8)
* **Exécution** : 100 % locale sur l'appareil (zéro cloud, zéro consommation de données internet pour l'analyse)
* **Système requis** : Android 7.0 (API 24) ou supérieur (optimisé pour Samsung Galaxy S9 et ultérieurs)
